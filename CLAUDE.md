# Apartment (three.js)

First-person walkthrough of a real apartment, built asset by asset from the owner's photos.
Run: `npm run dev`. Dimensions are estimates in `src/config.js` (metres; x = east, y = up, z = south).

**At the start of a session, check `feedback/` for unprocessed `feedback-*.json` files** (see
`feedback/README.md`) — they are notes the owner made in the preview with real screenshots. Process
them, then move the files to `feedback/processed/`.
